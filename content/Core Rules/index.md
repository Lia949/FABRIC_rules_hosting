This chapter explains the basic rules of F.A.B.R.I.C. 
# Rolling checks
**Skill check**
Every skill check uses one [[Characterstats#Attributes|Attribute]]  and one [[Characterstats#Skills|Skill]]. Add the attribute value to the skill value. Then roll that number of six-sided dice (D6). Every 1-3 is a failure, every 4-6 a success. Count the number of successes and compare it to the Difficulty of the Check (DC). If the DC is at least met, the check is successful. Each additional point counts as [[#Quality]]. 
**Attribute check**
Attributes checks only depend on that one requested attribute. Take double of the attribute value to roll the check. 
**Improvised use**
Using a similar skill to do something (eg. cooking instead of alchemy) can be allowed by the DM. Then only half of the skill value can be used.
## Quality
The Quality represents how well the desired outcome was achieved.
> [!tip] Quality  =  Number of Successes  -  Check DC
## Advantage and Disadvantage
A roll with advantage counts 3,4,5,6 as successes and only 1,2 as failures. A roll with disadvantage counts only 5,6 as successes and 1,2,3,4 as failures.
## Bonus and Penalty
Every check can have bonuses and penalties. These add or remove the specified number of dice before rolling the check.
## Critical success and failure
If you would have succeeded even with disadvantage you have a critical success.
If you would have failed even with advantage you have a critical failure. 
# Helping
To help an ally roll your dice as if you attempted the same check. They get your successes as [[#Bonus and Penalty|Bonus]].
# Dice Limit (optional)
As the characters level up there might be a lot of dice to roll at some point. A convenient
rule is to only roll half the dice and double the resulting successes instead. The threshold
for this is set to 10 dice currently. Uneven numbers simply add one roll that is not
doubled afterwards.
