**Move** (only if the main action is not move)
- stand up
	-3 penalty for main action
- walk
	move the speed in meters
- run
	move the speed x 2 in meters, penalty of -2 for main action

**Talk**
Say one sentence.

**Think**
Skill check that is based on knowledge. Penalty of -2 for main action.

**Reload**
Some ranged weapons only need a side action to reload but others need full actions. Check the weapon card to see what applies.

**Item**
Drop item/weapon. Take item/weapon from belt.

**Dodge**
Avoid ranged or close combat attacks from one direction. Roll seperately for each dodged attack and take a penalty of the number of dodged attacks halfed. 
Check on MOT, the successes count as your resistence/defense value. Diving to the ground gives a +2 bonus to dodge but the character is then on the ground.
