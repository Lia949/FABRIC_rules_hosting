Skills represent specifically trained processes. Everybody has Basic Skills on the Character sheet (but it's not required to have them above 0). On top a character can have as many Personalized Skills as they want. 
# Basic Skills
- Perception
- General knowledge
- Insight
- Self-control
- Animal handling
- Investigation
- Rhetoric
- Athletics
- Stealth
- Nature
- Medicine
- Performance
# Personalized Skills
These can be basically everything. A good rule is to avoid highly specific or to broad skills but in the end it's up to the DM if they allow the skill.
