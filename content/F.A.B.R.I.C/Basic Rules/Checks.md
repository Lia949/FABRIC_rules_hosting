# Skill check
Every skill check uses one Attribute ([[Basic Attributes]] or [[Magic Attributes]]) and one [[Skills|Skill]]. Add the attribute value to the skill value. Then roll that number of six-sided dice (d6). Every 1-3 is a failure, every 4-6 a succes. Count the number of successes and compare it to the Difficulty of the Check (DC). If the DC is at least met, the check is successful. Each additional point counts as [[#Quality]]. 
**Improvised use**
Using a similar skill to do something (eg. cooking instead of alchemy) can be allowed by the DM. Then only half of the skill value can be used.

# Bonus and Penalty
Every check can have bonuses and penalties. These add or remove dice before rolling the check.

# Quality
The Quality represents how well the desired outcome was achieved.
> [!tip] Quality  =  Number of Successes  -  Check DC

# Helping
To help an ally roll your dice as if you attempted the same check. They get half of your successes as [[#Bonus and Penalty|Bonus]].

# Attribute check
Attributes checks only depend on that one requested attribute. Take double of the attribute value to roll the check. 

# Dice Limit (optional)
As the characters level up there might be a lot of dice to roll at some point. A convenient
rule is to only roll half the dice and double the resulting successes instead. The threshold
for this is set to 10 dice currently. Uneven numbers simply add one roll that is not
doubled afterwards.
