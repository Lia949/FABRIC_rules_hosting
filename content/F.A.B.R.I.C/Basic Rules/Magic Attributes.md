# Control 
**Short form**: CTR

# Source Points
**Short form**: SOP
**Used for**:  The resource for casting magic. 
# Channel Capacity
**Short form**: CAP
**Used for**:  The limit, how many  Source Points per combat round can be used without causing a [[Casting Magic#Magic Recoil|Magic Recoil]].
