# Healing light wounds
The Number of Dice can be used to roll, each success heals a light wound.
> [!danger] **Effect Level   =   Number of Dice**

# Stabilize severe wound
See [[Stabilizing]] of wounds for the effect. 
> [!danger] **Effect Level   =   2  x  Wound severity**

# Mutate
The Number of Dice can be used to roll, each success creates a light wound.
> [!danger] **Effect Level   =   2  x  Number of Dice**
