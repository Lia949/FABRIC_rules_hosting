# Item Level
The Item Level tells how strong, valuable or useful an item is. For each item the Level is equal to the sum of [[#Artistry value]], [[#Enchantment value]] and [[#Physical value]]. Some items are heavy or impractical to handle, these impose an [[#Obstruction Penalty]].

The following table gives some examples for Item Levels to get a feeling for wealth. Depending on your [[Influence]], Items can be acquired. This system is an alternative to commonly used money-based systems.

# Item value
## Artistry value
Reflects pure monetary value. Items with a high Artistry Value have valuable materials, artistic engravings and adornments or any other kind of beautification, that makes the item more valuable.
## Enhance value
This is the strength of the Enchantment on the item or it's technological refinement. 
- **Bonus on attribute**: Per 4 points of Enhance Value the item can give +1 bonus on an attribute (including size and speed)
- **Bonus on skill check**: Per 2 points of Enhance Value the item can give +1 bonus on a skill check. 
## Combat value
Each level of combat value of an item causes a corresponding [[#Obstruction Penalty (OP)]]!
- **Damage**: For each point of Physical Value the weapon can have a +1 Base damage.
- **Damage reduction**: For each point of Physical value the armor(specific to one body part) or shield can have a +1 damage reduction (DR)
# Obstruction Penalty (OP)
Sum the OP of your equipment. If the sum rounded is larger than your CON stat you take the difference as penalty on all checks that involve physical movement (including combat). You can have armor/weapons with [[#Refinement value]] to reduce their Obstruction Penalty.

| Combat value | Obstruction Penalty |     | Combat value | Obstruction Penalty |
| ------------ | ------------------- | --- | ------------ | ------------------- |
| 1            | 0.1                 |     | 6            | 1.3                 |
| 2            | 0.2                 |     | 7            | 1.8                 |
| 3            | 0.4                 |     | 8            | 2.4                 |
| 4            | 0.6                 |     | 9            | 3                   |
| 5            | 0.9                 |     | 10           | 3.6                 |

# Refinement value
This might vary slightly based on the technological advancement of your setting. As DM decide on a reduction of 0.1 - 0.5 [[#Obstruction Penalty (OP)]] per Refinement Value.
