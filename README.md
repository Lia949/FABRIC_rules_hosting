# Hosting of F.A.B.R.I.C

F.A.B.R.I.C is a set of Pen and Paper rules. They are maintained in this git repository: [https://github.com/Lia949/F.A.B.R.I.C.](https://github.com/Lia949/F.A.B.R.I.C..git). 

This project uses Quartz and Github pages to host these rules as a web wiki. Please note that the rules themselves are licensed with Creative Commons Attribution-NonCommercial 4.0 International License.
